A one-line sick-day excuse for the make.fun bounty "The Funniest Sick-Day Excuse" — half believable, all back pain, with the twist landing on the last word. The program writes the line to `entry.txt`, one breath under 200 characters.

> My back went on strike this morning and my physio says sitting is now a health hazard, so I'm calling in sick before my spine files a formal complaint.

## Run it

```sh
node main.ts && cat /output/entry.txt
```
